### Mục tiêu tuần 10:

Hiểu cơ bản AWS CDK và khác biệt với CloudFormation.

Triển khai kiến trúc AWS (EC2, API Gateway, ELB, ECS, Lambda, S3) bằng CDK, bao gồm Nested Stack và user data.

Sử dụng AWS Systems Manager: Patch Manager, Run Command, Resource Groups, Session Manager (logs, port forwarding).

Hiểu CloudFormation và sử dụng Cloud9 để tạo/chỉnh sửa template.
