### Week 2 Objectives:

Understand the core concepts of IAM and apply best practices in managing Users, Groups, Roles, and Policies.

Set up secure access, practice logging in, and perform role switching in AWS.

Understand the architecture and main components of VPC, and design a standard network with routing, security, and monitoring.

Create and configure a complete VPC, deploy EC2 instances, test connectivity, and monitor using AWS tools.

Set up Site-to-Site VPN and get familiar with deploying infrastructure using IaC.

Understand Amazon EC2, create and connect to Windows & Linux instances.

Deploy a Node.js CRUD application on EC2 and configure the application runtime environment.

Plan the project, define each member’s role, and draft the database design.
