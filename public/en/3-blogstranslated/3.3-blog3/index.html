Why organizations around the world are choosing AWS Transform for .NET

by Beatriz Maeireizo Tokeshi | on 15 MAY 2025 | in .NET, Announcements, Artificial Intelligence, AWS .NET Development, AWS Transform, Generative AI, Windows on AWS

AWS Transform for .NET is trusted by Speed, scale, and quality.

The modernization imperative and its challenges

Modernization is the process of transforming applications into cloud-optimized services, improving performance, scalability, and cost-efficiency, and accelerating innovation.

Organizations running .NET Framework applications face growing challenges with licensing costs, scalability, innovation, maintenance, and security. True modernization to cross-platform, Linux-ready applications opens the door to enhanced performance, scalability, and cost savings. By transforming these applications, businesses can leverage advanced cloud capabilities including containerization, microservices, serverless computing, and artificial intelligence (AI).

The challenge? Modernizing legacy .NET applications is complex and resource-intensive. Manual modernization can be time consuming, often delayed by competing priorities and the intricate nature of compatibility changes and refactoring.

Jordi Martin, CTO of Signaturit, shares, “Modernization has been a challenge from a resource and prioritization perspective.”

Introducing AWS Transform for .NET

AWS announces the general availability of AWS Transform for .NET, the first agentic AI experience for modernizing .NET applications at scale.

AWS Transform accelerates large-scale .NET application modernization by up to 4x. By using generative AI-powered .NET transformation agents under human supervision, modernization teams can reduce operating costs by up to 40%, and enhance quality and performance using generative AI Large Language Models (LLMs).

Jared Hill, Capgemini’s Cloud & Custom Applications Vice President A/NZ, shares, “It’s clear from the continued investment and roadmap that AWS Transform for .NET will lead the way in generative AI-powered application modernization.”

Modernization acceleration and productivity boost

AWS Transform reduces the time and effort required for .NET modernization by up to 4x.

  • Signaturit completed a project slated for 6–8 months in a few days.
  • Grupo Tress Internacional (GTI) reduced modernization effort by 70%, with 100% success.
  • Jarek Grzabel, AWS Cloud CoE Lead at SoftServe, revealed accelerating modernization efforts by 70-90%.
  • Caribbean Examinations Council (CXC) successfully modernized over 143,000 lines of code in under two days—resulting in an estimated savings of 270 developer hours.

“This acceleration enabled us to pursue critical modernization efforts that would have otherwise been out of reach.” Rodney Payne, CXC’s Director of Technology Innovation

By reducing the effort of transforming legacy .NET applications from Windows to Linux, AWS Transform helps customers see the return of investment (ROI) much faster.

Cost savings, performance, and security improvements

Modernization reduces operating costs associated with Windows Server licenses, version upgrades, and maintenance.

  • Thomson Reuters reduced technical debt by 70%.
  • PTT Digital saw 76% reduction in cloud infrastructure costs and 13X performance improvement by upgrading to .NET 8 on Linux powered by AWS Graviton.
  • Intelliflo estimates saving about 40% of the costs by modernizing to cross-platform .NET on Linux, and an additional 10% with AWS Graviton-based processors.

Grzabel of SoftServe says, “Modernization… provides up to 15 times better performance… Running .NET on Linux can additionally save at least 50% on the cost, including eliminated Windows licenses, and drastically improve security.”

Security was also strengthened through AWS Control Tower and native AWS security services for Axcess.io.

Large-scale modernization

AWS Transform for .NET’s unique capability of scaling modernization by porting hundreds of .NET applications in parallel boosts productivity even more.

  • EPAM observed more than 50% faster execution compared to manual methods.
  • Organizations can run .NET porting efforts with consistency through a unified web experience.
  • Experian achieved a remarkable 49-sprint reduction in total effort across seven upgrades, representing a 47% productivity gain with 80% automation in code transformation across 687,600 lines of code.
  • PwC Australia successfully transformed approximately 110,000 lines of code to .NET 8 within 7 hours, which can be translated into 30-50% gain in transformation efficiency across the entire SDLC.

Enhancing .NET porting quality with AI

AWS Transform leverages LLMs to intelligently convert legacy .NET code, enhancing code quality and security while maintaining test coverage and providing transparent transformations.

  • Customers and partners like GTI and TEKsystems achieved 100% transformation accuracy.
  • Hexaware Technologies saw over 90% code accuracy with minimal manual adjustments.
  • AWS Transform for .NET also uncovers and fixes vulnerabilities.
  • Planet DDS completed a transformation effort originally scoped for three months in less than a week, achieving a 90% codebase transformation success rate.

“This correct-by-default experience gives us the confidence to scale .NET modernization with speed and precision.” Rahul Khot, Vice President, Engineering, Planet DDS

Unifii partnered with Slalom and the combined effort helped cut the expected delivery timeline by ~30%.

Beyond code transformation: accelerating innovation

The benefits of AWS Transform for .NET are beyond code transformation—it’s about unlocking new possibilities, enabling organizations to be more agile, invest their savings to innovate faster, and motivate their personnel.

“Without AWS Transform for .NET, this application modernization initiative… would most likely have been be delayed or deprioritized… AWS Transform for .NET has introduced a new world for modernization at Signaturit.” Jordi Martin at Signaturit

Furthermore, AWS Transform for .NET offloads the labor-intensive, undifferentiated work of code porting and streamlines daily workflows, freeing developers to focus on high-impact tasks.

Conclusion

AWS Transform is the first agentic AI service for modernizing .NET applications at scale. By using Generative AI-powered .NET transformation agents, modernization teams can accelerate .NET application modernization, reduce operating costs, and enhance quality and performance using generative AI LLMs.

Ready to start your .NET modernization journey? Learn more about AWS Transform for .NET today.
