# Summary Report: “AWS Cloud Mastery Series #2”

### Event Objectives

- Introduce the DevOps mindset, culture, and key metrics
- Present AWS DevOps services for building complete CI/CD pipelines
- Demonstrate Infrastructure as Code using CloudFormation and AWS CDK
- Explore container services and modern deployment strategies
- Provide hands-on experience with monitoring and observability tools
- Share DevOps best practices and real-world case studies

### Speakers

Speakers have worked at AWS or AWS partners.

### Key Highlights

#### Welcome & DevOps Mindset

- Recap of previous AI/ML session and how DevOps accelerates ML workflows
- Core DevOps principles: collaboration, automation, measurement, continuous improvement
- Key performance metrics: **DORA metrics, MTTR, deployment frequency**

#### AWS DevOps Services – CI/CD Pipeline

- **Source Control**: CodeCommit, GitFlow vs Trunk-based workflows
- **Build & Test**: CodeBuild configurations, integrating automated testing
- **Deployment Strategies**: Blue/Green, Canary, Rolling deployments
- **CodePipeline**: Full orchestration with multi-stage automation
- **Live Demo**: End-to-end CI/CD pipeline execution  

#### Infrastructure as Code (IaC)

- **AWS CloudFormation**: Templates, stacks, and drift detection
- **AWS CDK**: Constructs, reusable patterns, multi-language support
- **Demo**: Deploying resources using CloudFormation and CDK
- Comparison: When to choose CloudFormation vs CDK  

#### Container Services on AWS

- Docker fundamentals and microservices architecture
- **Amazon ECR**: image storage, scanning, lifecycle policies
- **Amazon ECS vs EKS**: deployment strategies, scaling, orchestration
- **AWS App Runner**: Simplified container deployment for developers
- **Case Study & Demo**: Comparing deployment flows across services  

#### Monitoring & Observability

- **CloudWatch**: Metrics, logs, dashboards, alarms
- **AWS X-Ray**: Distributed tracing and latency analysis
- **Demo**: Full-stack observability setup from application to infrastructure
- Best practices for alerting, dashboards, and on-call workflows 

#### DevOps Best Practices & Case Studies

- Deployment techniques: **feature flags**, A/B testing
- Automated testing integrated into CI/CD
- Incident management workflows and postmortems
- Case studies: DevOps adoption in startups and enterprise-scale transformations  

### Key Takeaways

#### DevOps Mindset

- Collaboration + automation = faster, safer delivery
- Continuous improvement using objective metrics (DORA)
- Shift-left practices: testing, security, monitoring  

#### Technical Architecture

- Build fully automated CI/CD pipelines using CodePipeline
- Use IaC (CloudFormation/CDK) for consistent, repeatable environments
- Adopt container orchestration with ECS/EKS depending on workload
- Implement strong observability with CloudWatch + X-Ray 

#### DevOps Strategy

- Move toward automated deployments and Git-based workflows
- Establish monitoring standards and alerting baselines
- Incorporate feature flags and progressive deployments
- Build a learning culture with postmortems and retrospectives  

### Applying to Work

- Implement CI/CD pipelines for ongoing and future projects
- Use IaC to standardize infrastructure provisioning
- Adopt containers and evaluate ECS/EKS for microservices
- Improve observability with dashboards, alarms, tracing
- Integrate automated tests directly into deployment pipelines
- Use deployment strategies (blue/green, canary) to reduce risk
